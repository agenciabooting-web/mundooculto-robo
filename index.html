About

Mundo Oculto Robo is a single-user tool run by the owner of the Mundo Oculto channel on their own computer. It uploads videos that the owner has produced and reviewed, and schedules them on the owner's channel through the YouTube Data API. It is not offered to the public and has no user accounts.

Privacy Policy

Last updated: November 16, 2026

  • Who can use it: only the channel owner, who authorizes the tool with Google OAuth.
  • Data accessed: the owner's own channel information (name, ID, statistics) and the owner's own videos (upload, metadata, processing status, thumbnails, playlists). No data from other YouTube users is accessed.
  • Storage: the OAuth token is stored only on the owner's local computer. No YouTube data is stored on any server.
  • Sharing: no data is sold, shared or transferred to third parties.
  • Revoking access: access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token removes all stored credentials.
  • Google policies: this tool uses YouTube API Services. See the Google Privacy Policy. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
  • Contact: through the channel's About page on YouTube.

Terms of Service

  • This tool is for the channel owner's personal use only.
  • By using it, the user agrees to the YouTube Terms of Service.
  • The tool does not automate views, likes, comments or subscriptions.
  • The tool is provided as-is, with no warranty.

Política de Privacidade (Português)

O Mundo Oculto Robo é uma ferramenta de uso exclusivo do dono do canal Mundo Oculto. Ela roda no computador dele e envia e agenda os vídeos do próprio canal pela API do YouTube.

Ela acessa apenas os dados do próprio canal e dos próprios vídeos, nunca dados de outros usuários. O token de acesso fica só no computador local, e nenhum dado é vendido ou compartilhado.

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Ao usar a ferramenta, valem os Termos de Serviço do YouTube e a Política de Privacidade do Google.
